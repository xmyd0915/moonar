# Sources and licenses

MoonAr is an independent implementation under the repository's MIT license.
No source code or Git history was copied from MoonPkgConfig, MoonPatch, MoonGitAttrs
or another archive parser. The algorithms were written for this project with AI
assistance. The generated MoonBit project guide and hook template came from the
MoonBit project initialization tool.

## Format and behavior references

- [GNU ar](https://sourceware.org/binutils/docs/binutils/ar.html): archiver behavior,
  deterministic mode, duplicate members and symbol indexes.
- [LLVM ar](https://llvm.org/docs/CommandGuide/llvm-ar.html): GNU/BSD/Darwin formats,
  member listing, extraction and deterministic mode.
- [LLVM ArchiveWriter.cpp, version 18.1.3](https://github.com/llvm/llvm-project/blob/llvmorg-18.1.3/llvm/lib/Object/ArchiveWriter.cpp):
  checked the Darwin declared-size padding behavior after an independent test
  exposed it. No implementation code was copied.
- [Debian deb(5)](https://manpages.debian.org/bookworm/dpkg-dev/deb.5.en.html):
  outer ar members and the `debian-binary` version marker.
- [MoonBit language documentation](https://docs.moonbitlang.com/en/latest/language/packages.html):
  package access control; `Archive` hides its representation to protect offsets.

These are references, not endorsements. The implementation covers the boundaries
documented in README rather than every historical ar dialect.

## Dependencies and verification tools

The library uses `moonbitlang/core` (Apache-2.0). Native filesystem and process-exit
code imports `moonbitlang/x@0.5.5` (Apache-2.0); the parser itself does not import it.
Dependencies are resolved by MoonBit and are not vendored into this repository.

GNU binutils, LLVM and Python run as separate verification programs. Their source
and binaries are not included. CI setup actions are referenced at fixed commits;
they and the compiler are build infrastructure, not part of the MoonAr library.

## Example data

All committed files in `examples/data/` are generated by `tools/examples.py` from
short self-authored data. The small Debian example has a control record and one
greeting file; it contains no installation scripts. The deliberately truncated
archive is a negative example. The test C function used by
`tools/verify_archives.py` is also self-authored and generated locally.

Examples and verification scripts use the repository's MIT license. No external
SDK, package payload, private build output or personal information is included.
