# 通用 ar 库的范围与验收

MoonAr 实现通用 Unix ar 库的完整归档生命周期：读取、成员访问、thin 引用处理、创建、
编辑、格式转换与符号索引维护，并提供可接入构建流程的命令行。主要兼容 GNU、BSD、Darwin 和 Microsoft COFF；
比较能力用于检查构建复现和编辑结果。

0.6.2 的范围以以下矩阵为准。各功能均有实现和可运行验收入口。

## 设计与验收原则

普通归档与 thin 使用独立类型，避免将外部声明大小当成容器切片。加载不隐式发生，
调用方可以控制根目录、路径策略和累计预算。

编辑针对普通成员序列，保留重名项；名称表、头部偏移和索引由最终序列重新计算。
自动索引从编辑完成后的对象发现定义，避免继续使用被替换或删除对象的旧映射。

兼容性同时检查“参考工具生成、MoonAr 读取”和“MoonAr 写出、参考工具消费”。
静态库还需经真实对象符号核对、链接和程序运行；异常路径独立验证原文件保留。
Mach-O 的跨平台链接验证与本机程序运行在结果中分别报告。
